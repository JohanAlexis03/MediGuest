# Visión del proyecto — MediQuest

## El problema

Una estudiante de Atención Prehospitalaria necesita repasar constantemente conceptos, procedimientos y situaciones clínicas. Hoy estudia con apuntes, consulta fuentes en internet y se apoya en compañeros que le preguntan y la corrigen.

Dolores detectados:

1. **Desinformación en internet:** al buscar temas como "cómo detener una hemorragia", aparece información poco confiable o incorrecta.
2. **Información superficial:** las fuentes consultadas no profundizan; parte del conocimiento válido solo se transmite en clase.
3. **Falta de método de estudio:** la estudiante aún no encuentra un método de estudio que le funcione.

## La solución

MediQuest no compite con internet como fuente de información: **es el antídoto contra la desinformación**. Es un método de estudio estructurado donde el conocimiento validado se presenta en forma de casos clínicos interactivos:

```
Caso clínico → información del paciente → signos y síntomas → signos vitales →
hallazgos → imagen/radiografía (si aplica) → preguntas → evaluación →
retroalimentación detallada → registro del resultado → progreso
```

> MediQuest es un gimnasio del razonamiento clínico: no guarda la información para leerla, la pone dentro de los casos para **practicarla**.

## Objetivo general

> Desarrollar una aplicación móvil que permita a los estudiantes de Atención Prehospitalaria resolver casos clínicos interactivos, con el fin de fortalecer el razonamiento clínico y la toma de decisiones.

## Objetivos específicos

1. Diseñar una estructura de casos clínicos interactivos que presente información relevante del paciente, como antecedentes, signos vitales, síntomas y hallazgos clínicos.
2. Implementar un módulo que permita a los estudiantes analizar y responder preguntas relacionadas con los casos clínicos.
3. Implementar un sistema de evaluación que permita calificar las respuestas y proporcionar retroalimentación al estudiante.
4. Registrar los resultados obtenidos por los estudiantes para realizar seguimiento de su progreso en la resolución de casos clínicos.

## Regla de alcance

Cada funcionalidad propuesta debe responder: **¿ayuda directamente a resolver casos clínicos y a aprender de ellos?** Si la respuesta es no, es una funcionalidad secundaria o futura.
